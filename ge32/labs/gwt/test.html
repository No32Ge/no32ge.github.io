5. 代码示例

GWT.js 使用示例代码

// 显示提示信息 GWTools.showMessage("操作成功！"); // 复制HTML内容 GWTools.copyToClipboard("elementId"); // 复制纯文本 GWTools.copyToClipboard("elementId", "", {asText: true}); // 将div标签转换为section标签 GWTools.divToSection("containerId"); // 将section标签转换回div标签 GWTools.sectionToDiv("containerId"); // 自定义标签替换 GWTools.replaceTagsById("containerId", "span", "p");
