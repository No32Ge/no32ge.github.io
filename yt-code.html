YouTube视频下载器 Python代码解析与教学 import os import yt_dlp def download_youtube_video(url: str, output_path: str): """ 从 YouTube 下载视频并保存为 mp4，文件名自动使用视频标题 :param url: YouTube 视频链接 :param output_path: 输出文件路径或目录 """ # 如果传的是目录，就在里面用视频标题作为文件名 if os.path.isdir(output_path) or output_path.endswith(("\\", "/")): os.makedirs(output_path, exist_ok=True) is_dir = True else: os.makedirs(os.path.dirname(output_path) or ".", exist_ok=True) is_dir = False # 先获取视频信息，提取标题 with yt_dlp.YoutubeDL() as ydl: info = ydl.extract_info(url, download=False) title = info.get('title', 'video') safe_title = "".join(c if c.isalnum() or c in " _-" else "_" for c in title) # 根据是否是目录决定最终输出路径 if is_dir: output_path = os.path.join(output_path, f"{safe_title}.mp4") ydl_opts = { 'format': 'bestvideo+bestaudio/best', 'outtmpl': output_path, # 输出文件路径 'merge_output_format': 'mp4', # 合并为 mp4 'quiet': False, } with yt_dlp.YoutubeDL(ydl_opts) as ydl: ydl.download([url]) 代码解析 1 导入必要的库 代码首先导入两个必要的Python库： os：用于处理文件和目录路径 yt_dlp：YouTube视频下载的核心库，是youtube-dl的一个分支 2 函数定义 定义了一个函数download_youtube_video，它接受两个参数： url：YouTube视频的URL链接 output_path：输出路径，可以是文件路径或目录路径 3 路径处理逻辑 代码检查output_path是目录还是文件路径： 如果是目录，确保目录存在（使用os.makedirs创建） 如果是文件路径，确保其父目录存在 设置is_dir标志以便后续使用 4 获取视频信息 使用yt_dlp.YoutubeDL()提取视频信息： ydl.extract_info(url, download=False)获取视频元数据而不下载 从元数据中提取视频标题并创建安全文件名（移除非法字符） 5 设置下载选项 配置下载参数： format：选择最佳视频和音频质量 outtmpl：设置输出文件路径模板 merge_output_format：指定合并为mp4格式 quiet：设置为False以显示下载进度信息 6 执行下载 使用配置好的选项创建YoutubeDL实例并调用download方法开始下载。 使用前准备 在使用此代码前，需要安装yt-dlp库： pip install yt-dlp 注意事项 这里下载视频仅仅只是作为学习用途。 使用示例 # 下载视频到指定目录 download_youtube_video("https://www.youtube.com/watch?v=example", "./videos") # 下载视频并指定完整路径 download_youtube_video("https://www.youtube.com/watch?v=example", "./videos/my_video.mp4") 本教学页面仅用于教育目的，请遵守相关法律法规和平台条款 1
