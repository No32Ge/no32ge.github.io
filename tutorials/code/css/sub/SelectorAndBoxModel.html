🔍CSS选择器详解

选择器的作用

🎯

CSS选择器用于"选择"您想要样式化的HTML元素。通过选择器，我们可以精准定位页面中的特定元素或元素组。

#️⃣基本选择器

通过元素类型、类名或ID选择元素

p { /* 选择所有段落 */
  color: blue;
}

.highlight { /* 选择类名为highlight的元素 */
  background: yellow;
}

#main-title { /* 选择ID为main-title的元素 */
  font-size: 2.5rem;
}

🧩组合选择器

基于元素之间的关系选择元素

div p { /* 选择div内的所有段落 */
  margin: 10px 0;
}

ul > li { /* 选择ul的直接子元素li */
  list-style: none;
}

h1 + p { /* 选择紧接在h1后的段落 */
  font-weight: bold;
}

🎭伪类选择器

基于元素状态选择元素

a:hover { /* 鼠标悬停在链接上时 */
  color: red;
}

li:first-child { /* 选择第一个li元素 */
  font-weight: bold;
}

input:focus { /* 输入框获得焦点时 */
  border-color: blue;
}

📦属性选择器

基于属性或属性值选择元素

a[target="_blank"] { /* 选择在新标签页打开的链接 */
  background-color: yellow;
}

input[type="text"] { /* 选择所有文本输入框 */
  padding: 8px;
}

img[alt] { /* 选择所有有alt属性的图片 */
  border: 1px solid #ccc;
}

📦CSS盒模型详解

什么是盒模型？

📐

在CSS中，每个元素都被视为一个矩形盒子。这个盒子由四个部分组成：内容(content)、内边距(padding)、边框(border)和外边距(margin)。

.box {
  width: 300px; /* 内容宽度 */
  height: 200px; /* 内容高度 */
  padding: 20px; /* 内边距 */
  border: 5px solid #333; /* 边框 */
  margin: 30px; /* 外边距 */
}

标准盒模型 vs 替代盒模型：

默认情况下，元素的宽度(width)和高度(height)只包括内容区域。添加内边距和边框会增加盒子的总大小。

使用 box-sizing: border-box; 可以改变这种行为，使宽度和高度包括内容、内边距和边框。

.standard-box {
  box-sizing: content-box; /* 默认值 */
  width: 300px;
  padding: 20px;
  border: 5px solid #333;
  /* 总宽度 = 300 + 40 + 10 = 350px */
}

.border-box {
  box-sizing: border-box; /* 推荐设置 */
  width: 300px;
  padding: 20px;
  border: 5px solid #333;
  /* 总宽度 = 300px (内容自动调整) */
}

💡实用技巧

1. 全局设置box-sizing：在CSS开头添加以下代码，使所有元素使用border-box模型：

*, *::before, *::after {
  box-sizing: border-box;
}

2. 使用margin: auto; 可以轻松实现水平居中：

.container {
  width: 80%;
  margin: 0 auto; /* 水平居中 */
}

3. 使用负margin可以创建重叠效果，但需谨慎使用。
